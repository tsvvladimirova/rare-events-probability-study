# When Does the Unlikely Become Likely?

## Project Overview

This project investigates how the probability of observing a rare event at least once changes as the number of opportunities increases.

The investigation will combine probability theory, mathematical modelling, Python simulations, and statistical analysis.

## Research Question

How does the number of independent trials affect the probability of observing a rare event at least once?

## Objectives

- Develop and explain a mathematical model for the probability of at least one occurrence.
- Formulate hypotheses before conducting experiments.
- Implement simulations in Python.
- Compare theoretical predictions with simulation results.
- Analyze the results and discuss the assumptions and limitations of the model.

## Methodology

The project will begin with a mathematical formulation of the problem. The model will then be implemented in Python and tested under different conditions. The theoretical and simulated results will be compared and interpreted.

## Project Status

In progress — the research question and initial project structure are being developed.
